# BoltSpec – automated bolt-torque & tap-drill reference site

362 static pages generated by one zero-dependency Python script. Monetised by Amazon affiliate links (day 1) and AdSense (after a custom domain).

## Launch (≈30 min)

1. **GitHub** – create a public repo `boltspec`, upload every file in this folder (keep `.github/`), commit to `main`.
2. **Cloudflare Pages** – dash.cloudflare.com → Workers & Pages → Create → Pages → Connect to Git → pick the repo.
   Build command: `python build.py` · Output directory: `dist` · Deploy.
3. **Set your URL** – edit `config.json` on GitHub: put the `https://<name>.pages.dev` URL in `base_url` and your email in `contact_email`. Commit. (Auto-redeploys; IndexNow pings Bing automatically.)
4. **Google Search Console** – add the URL (HTML-tag or DNS verification), then Sitemaps → submit `sitemap.xml`. One time only.
5. **Amazon Associates** – sign up at affiliate-program.amazon.com with the site URL, put your tracking ID (e.g. `boltspec-20`) in `amazon_tag`. Commit.
6. **Later, when traffic arrives** – buy a domain (~$10/yr), add it in Cloudflare Pages → Custom domains, update `base_url`, apply to AdSense, put `ca-pub-…` in `adsense_client`. Ads and `ads.txt` appear automatically.

## What runs by itself

| Trigger | What happens |
|---|---|
| Any commit | Tests run (formulas vs. reference values, link check) → Cloudflare rebuilds and deploys → IndexNow submits all URLs |
| Weekly | Health check of the live site; GitHub emails you only if it fails |

## Files

- `build.py` – data, formulas, templates, sitemap. Add threads/classes to the tables at the top to create more pages.
- `test_build.py` – run before trusting any data change.
- `config.json` – the only file you edit.
- `.github/workflows/site.yml` – automation.

Local preview: `python build.py && python -m http.server -d dist 8000`
